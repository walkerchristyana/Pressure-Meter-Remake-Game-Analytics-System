# Pressure-Meter-Remake-Game-Analytics-System
A 2D decision-based game exploring player choices, consequences, and emotional responses, now expanded with SQL game telemetry to analyze player behavior, response times, stat changes, and outcomes.

#Brief/Purpose 

Pressure Meter is a 2D decision-based game originally created to explore how players respond to stressful situations through choice-driven gameplay. Players move through different scenarios while managing four core stats: Threat, Awareness, Stability, and Resistance. Each decision affects these values and can lead to different paths and endings, making the game focused on player choice, consequences, and emotional decision-making.

The newest update expands Pressure Meter into a game telemetry and player analytics project. I am adding a SQL database that records player choices, response times, stat changes, session behavior, and final outcomes. This allows me to analyze how players move through the game, which decisions are most common, where players hesitate, and how different choices influence outcomes. The goal is to combine game development, SQL, data analysis, and UX research to better understand player behavior and use gameplay data to inform future design decisions.
